## Concepts Learned

### Object-Oriented Programming (OOP) in C#
- **Encapsulation**: Wrapping data and methods within classes to protect and manage them effectively.
- **Inheritance**: Enabling code reuse by deriving new classes from existing ones.
- **Polymorphism**: Achieved via:
  - **Method Overriding**: Changing the behavior of a base class method in a derived class.
  - **Method Overloading**: Defining multiple methods with the same name but different parameters.
- **Abstraction**: Simplifying complex systems by showing only essential details through abstract classes and interfaces.

### Collections Framework in C#
- **Lists**: Dynamic arrays for managing a collection of objects.
- **Dictionaries**: Key-value pairs for efficient data storage and retrieval.
- **Queues and Stacks**:
  - **Queue**: First-In-First-Out (FIFO) collection.
  - **Stack**: Last-In-First-Out (LIFO) collection.
- **HashSets**: Collections ensuring all elements are unique.
- **ArrayLists**: Non-generic collections that can store elements of various types and resize dynamically.

### Arrays in C#
- Fixed-size collections for storing elements of the same type.
- Used for situations requiring efficient and predictable memory allocation.
