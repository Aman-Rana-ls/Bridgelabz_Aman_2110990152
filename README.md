DDL (Data Definition Language) : Create and modify tables with CREATE and ALTER. Delete tables with DROP.

DQL (Data Query Language) : Retrieve data with SELECT. Filter data with WHERE. Sort data with ORDER BY.

DML (Data Manipulation Language) : Insert data with INSERT. Update data with UPDATE. Delete data with DELETE.

DCL (Data Control Language) : Grant permissions with GRANT. Revoke permissions with REVOKE.
